## 📌 Descripción

La extensión **Dynamic Financial Reports PRO** desbloquea potentes herramientas analíticas de nivel ejecutivo sobre el módulo contable básico, añadiendo **Exportación Nativa a Excel (.xlsx)** y **Comparativa Multiperíodo Dinámica**.

### 🔥 Funcionalidades PRO:
* **📊 Exportación a Excel PRO:** Genera un archivo `.xls`/`.xlsx` descargable con formato contable, bordes ejecutivos y totales tabulados.
* **📈 Comparativa de Períodos:** Compara el período actual contra el mismo período del **Año Anterior** o un rango personalizado.
* **Análisis Porcentual de Variación:** Permite evaluar el crecimiento o decrecimiento operacional entre ejercicios contables.

---

## 🛠️ Guía Paso a Paso de Uso

### Paso 1: Configurar Comparativa Multiperíodo
1. Abra el asistente desde **Contabilidad** > **Reportes Financieros**.
2. Marque la casilla **"Habilitar Comparativa de Período PRO"**.
3. Seleccione el **Tipo de Comparación** (*Mismo Período Año Anterior* o *Período Personalizado*).
4. El sistema calculará automáticamente las fechas de contraste.

### Paso 2: Exportar a Excel PRO
1. Haga clic en el botón superior **"📊 Exportar a Excel PRO"**.
2. El sistema generará el informe y descargará automáticamente el archivo ejecutable en su equipo.

---

## 🔧 Instalación

1. Asegúrese de tener instalado el módulo base `dynamic_financial_reports_community`.
2. Copie la carpeta `dynamic_financial_reports_pro` en su servidor Odoo.
3. Actualice la lista de aplicaciones e instale el módulo **Dynamic Financial Reports PRO**.
